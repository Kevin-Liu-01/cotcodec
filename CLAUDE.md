# CoTCodec

Refer to [AGENTS.md](AGENTS.md) for the complete project guide.

Read `program/PROGRAM.md` and `program/state.json` for the current research
program, state and next actions. `HANDOFF.md` has the latest session handoff.

This is a research project — the goal is rigorous, reproducible experiments.
The harness is the product. Positive and negative results are equally valuable.

For novel directions, new mechanisms, or experiments over 8 GPU-hours, obey
`.claude/rules/research-gauntlet-loop.md` (loop until 100 or an honest exit).

This repository is public. Never commit secrets, host addresses, employer-internal
material or private datasets. Old work lives read-only under `legacy/`.
