## 0. The organizing observation (shared by all three candidates)

Every 2026 fast-weight memory writes its state from inputs that already depend on the state (the k/v/gate projections read a residual stream shaped by earlier memory reads and by attention over earlier records). "Subtract, Transport, or Replay? Auditable Deletion from Language-Model Memory" (2607.27539, v2 2026-08-13, full text read) proves the consequence for native Kimi Delta Attention: a record's influence is not addressable after later computation because "omission changes the later transition and write inputs" (median relative suffix-input differences 0.150/0.246/0.025/0.088 for k/v/g/beta); the corpus-pooled recurrent contribution shifts 12–49% with the suffix, 8–49% after a decay-ledger correction, and only checkpoint replay verifies deletion. Its Proposition 1 states the escape hatch as a condition, not a design: "If present and omitted trajectories receive identical numerical (A_t, b_t) after boundary tau, then Delta_T = Delta_tau A_{tau+1} ... A_T." Its §6 names as future work "segmented, record-wise ingestion for imprint-free writes" and "streaming certificates that remain valid under later admissions", but its constructive result is a support-vector memory retrofit on frozen Gemma 3 whose deletion path is decremental SVM learning (Cauwenberghs–Poggio) that "fails ~60%" and falls back to an O(N) exact refit.

The three candidates below turn that condition into an architectural constraint for the gated-delta-rule family — **read-free, document-blocked writes**: the per-token write factors (k_t, v_t, alpha_t, beta_t) of one ingested item must be numerically independent of the memory and of every other item. Under that constraint the state is an associative composition of per-item affine maps, so exact deletion costs O(log N) compositions (segment tree of exclusive products), exact reset is trivial, all-items leave-one-out attribution costs O(N) compositions (suffix sweep), and per-item influence is boundable by clipping the write factors. What is *not* free is the model's ability to use cross-item context while writing; pricing that constraint is the empirical program. Every candidate carries the SR-TTT/prefix-invariance causality protocol (startup self-tests, generation exact match with paired McNemar, storage/addressing/readout decomposition, two-forward-pass audit) as a mandatory doctor.

Plain-text algebra used throughout (state S in R^{d_v x d_k}, unit-norm keys):

```
S_t = S_{t-1} A_t + b_t,   A_t = alpha_t (I - beta_t k_t k_t^T),   b_t = beta_t v_t k_t^T
(A, B) o (A', b') = (A A', B A' + b')                       # associative composition of affine maps
(A_D, B_D) = o_{t in D} (A_t, b_t)                           # one item/document D
S_N = S_0 A_{1:N} + B_{1:N}
S_N^{(-j)} = S_{j-1} A_{j+1:N} + B_{j+1:N}                    # exact state with item j never written
||A_t||_2 <= 1 for alpha_t <= 1, 0 <= beta_t <= 1            # compositions are non-expansive
```

The precondition for `S_N^{(-j)}` to equal full replay without item j is exactly Proposition 1 of 2607.27539: identical (A_t, b_t) for every other item. Natively false; enforced here by construction.

## 1. Candidate 1 (cheap-decisive) — `exclusive-composition-deletion-ledger`

**Claim.** A drop-in fast-weight memory on a frozen base whose write factors come from document-blocked (independently encoded) records admits exact, attestable deletion and reset at O(log N) cost and exact per-record attribution at O(N) cost, and passes a deletion battery that approximate unlearning of the same memory fails; measuring what document-blocking costs on recall is the price of the guarantee.

**claim_scope:** attachment-capability.

**Mechanism.** Frozen backbone (registry `qwen3-0.6b-base`, Qwen3-0.6B-Base rev da87bfb6) prefill each record D_j under a document-blocked attention mask with APE-style shared-prefix/temperature/scale alignment (2502.05431) so its hidden states are numerically independent of other records. A TTT-NTP-style write head (2606.21803; Apache-2.0 code, pushed 2026-08-30) maps hidden states to keys k_t and next-position value targets v_t; the memory is either (a) the gated delta rule with per-record affine factors (A_D, B_D) stored in a segment tree, or (b) the commutative ridge form: sufficient statistics (Kt K + lambda I, Vt K) summed over records, read W = V K^T (K K^T + lambda I)^{-1}, deletion by subtraction and re-solve in O(d_k^3). Reads at decode: y_t = S phi(q_t) added to the backbone's MLP path as in TTT-NTP. Deletion of D_j: S <- S_{j-1} A_{j+1:N} + B_{j+1:N} via the tree (O(log N) products of 128x128 and d_v x 128 matrices, about 0.1 GFLOP for N = 1,000); also drop D_j's blocked KV cache (exact because other records' KV never attended to it). Reset: S <- S_0. Attribution: one backward suffix sweep yields every S_N^{(-j)}; influence I_j(q) = ||(S_N - S_N^{(-j)}) q||. Attestation: hash chain r_j = H(r_{j-1} || H(A_j) || H(B_j) || meta_j); a deletion certificate is (r_{j-1}, H(A_j), H(B_j), H(S^{(-j)}_tree), H(S^{(-j)}_replay)) recomputed by a CPU fp64 oracle over the stored factor lists under a fixed arithmetic order; equality is the receipt. Phase 0 of the pilot also runs the audit half (G6): E2-TTT 340M/1.3B (zeyun-zhong/e2-ttt-{mlp,swiglu}-{340M,1.3B}-15B, HF, verified present 2026-09-01) and FwPKM l12 (SakanaAI/fwpkm-l12-*, 8 checkpoints, verified present) under SR-TTT startup causality self-tests, two-forward-pass prefix-invariance audit, needle-outside-window stratification, generation exact match with paired McNemar — and measures how far their native (read-during-write) states are from deletable by applying the 2607.27539 static/transport receipts and reporting the deviation from replay.

**What is new (delta vs three closest priors).**
1. vs 2607.27539 "Subtract, Transport, or Replay?" (https://arxiv.org/abs/2607.27539, v1 2026-07-30, v2 2026-08-13; abs + full HTML read): they show native KDA is non-addressable and retrofit an SVM memory whose deletion is decremental-SVM with ~60% fallback to O(N) refit; we make the *delta-rule family itself* addressable by enforcing their Proposition 1 architecturally and delete in O(log N) via associative exclusive composition, with all-records leave-one-out and hash-chained streaming receipts — the two items their §6 lists as future work.
2. vs TreeWY (https://arxiv.org/abs/2608.20961, 2026-08-21; abs read): TreeWY uses the WY/affine algebra of the gated delta rule to reconstruct the one *accepted* draft branch without snapshots; we use the same associativity for *exclusion* of an arbitrary committed record plus attestation — different operation (deletion, not speculative rollback) and a different precondition (read-free writes) that TreeWY does not need.
3. vs Certified Data Removal (https://arxiv.org/abs/1911.03030, ICML 2020; abs read): certified removal covers trained linear classifiers with a Newton-step mechanism and a statistical indistinguishability certificate; here the object is test-time state, deletion is exact (not (epsilon,delta)-certified) because the state is an explicit function of per-record factors, and the certificate is a replay-equality receipt.
Also positioned against: DeltaLog (2608.15533; bounded update log for decoding throughput, no deletion; abs read), Tail-Replay (2608.30310; approximate suffix reconstruction, 92.8–99.9% quality; abs read), RW-TTT (2605.28053; owner/version tagging only; abs read), In-Context Unlearning (2310.07579; label flips in context; abs read), ICCU (2605.27138; refusal rules; abs read), MUNKEY (2603.15033; key deletion in a vision memory-augmented transformer; abs read), Block-Attention (2409.15355) and APE (2502.05431) which introduce independent record encoding for KV reuse/latency, not for deletability of a learned state.

**Falsifiable predictions.**
- P1 (algebra): on a CPU fp64 oracle with synthetic MQAR factor lists, the exclusive composition equals replay-without-record to <= 1e-12 relative Frobenius for N <= 10,000 records; in fp32 <= 1e-5; the same recipe applied to a control whose write factors *do* read the state deviates >= 5% relative (2607.27539 measured 12–49% on native KDA).
- P2 (behavior): on Qwen3-0.6B-Base + blocked ridge memory over 200 TOFU-style records at 8–32K, after deleting record j its generated exact-match recall and paraphrase recall equal the never-stored model within 1 pt, locality on other records changes <= 0.5 pt, and per-prompt next-token KL to the never-stored model is <= 1e-6 nats (fp64 memory arithmetic); matched-compute gradient-ascent unlearning of the same fast weights leaves >= 15% residual recall or >= 2 pt locality damage.
- P3 (price of the constraint): document-blocked encoding with APE alignment loses <= 5 pts on RULER NIAH/QA at 8–32K relative to sequential encoding on the frozen base (APE reports 98%/93% retention on RAG/ICL); a loss > 10 pts kills the frozen-base route.
- P4 (audit half): E2-TTT's 93.6% S-NIAH-1 at 16K survives startup-causality and prefix-invariance self-tests at >= 90% (its chunk-start-gradient approximation is causal by construction); FwPKM's 4K->128K claim retains >= 60% under generation exact match with needles outside every non-parametric path. Pre-registered as bands; either outcome is reported.

**Kill conditions.** fp32 exclusive composition deviates > 1e-3 relative from replay at N = 1,000 (numerical non-associativity too large for a bf16/fp32 ledger); or document-blocking costs > 10 pts RULER on the frozen base and the ridge memory recovers none of it (deletability then requires training-time design -> Candidate 2); or the 2607.27539 author publishes segmented ingestion with streaming certificates first — the delta then shrinks to the delta-rule algebra, all-records attribution and the audit, which is a methods note rather than a mechanism paper.

**Cheapest decisive pilot.** Phase 0 (CPU, no LM, 1 day): NumPy fp64 oracle for composition/exclusion/receipts; startup causality self-tests; retrieval-impossible control corpus for the metric off-by-one (SR-TTT); positive control MQAR. Phase 1 (frozen checkpoints, ~6–8 GPU-h on 8xH100): (a) audit arm on E2-TTT 340M/1.3B and FwPKM l12 (2 GPU-h); (b) constructive arm on `qwen3-0.6b-base` with blocked encoding + TTT-NTP ridge write, deletion battery (Beyond Perplexity D-level: recall, paraphrase, delay, locality, conflict) vs sequential encoding, replay oracle, static-subtract receipt, gradient-ascent unlearning (4 GPU-h); (c) optional cross-lingual probe with FLORES-200 paraphrases (delete the English record, test the German paraphrase — diagnoses meaning vs surface storage; Kevin's parallel data adds domain terminology but is not required). pilot_gpu_hours: 8.

**Controls.** Sequential (non-blocked) encoding on the same base; replay oracle; never-stored model; static-subtract and frozen-transport receipts (2607.27539 classes); gradient-ascent unlearning at matched compute; SWA+sinks-only no-memory arm (2608.28444 mandate); Tail-Replay 5–10% suffix reconstruction as the approximate state-fidelity comparator (2608.30310 mandate for any state claim); two-forward-pass prefix-invariance audit (2608.22876) and SR-TTT startup tests as doctors; Beyond Perplexity S/B/D ladder reporting (2607.00368); paired McNemar with disjoint seed pools.

**kevin_advantage.** The harness's deterministic replay, digest-pinned images and hash-chained audit record (AGENTS.md) are precisely the attestation machinery; 8xH100 is far more than needed; parallel translation data is optional (cross-lingual deletion probe). No unique data asset.

**collision_risk: medium** (high for the "segmented ingestion => exact deletion" half, which 2607.27539 §6 names as future work; low for the audit half and the delta-rule exclusive-composition/attribution algebra). Searches: see §5.

**Monitorability and safety.** Increases auditability: every read is attributable to records, every deletion is attestable, no effect on CoT. Scope must be stated as in 2607.27539: the deletion target is test-time state (memory + blocked KV), not pretrained weights or prior outputs. Data: TOFU (MIT), RULER (synthetic), FLORES-200 (CC-BY-SA); no production customer data in publication runs.

**Negative-result value.** If blocking is too costly on a frozen base, the field learns that deletable test-time memory must be designed in at training time (feeds Candidate 2). If fp32 composition is unstable, it quantifies the precision a state ledger needs (relevant to DAMP/DASC). The audit arm settles whether the strongest 2026 beyond-window TTT claims survive causality checks (G6) either way.

**targets_gaps:** G6, G7, G20.

## 2. Candidate 2 (moonshot) — `read-free-memory-band-hybrid`

**Claim.** A from-scratch hybrid in which *all* cross-record information flows through one fast-weight memory band whose write factors are computed by a memory-free, record-blocked writer stack (writes from below, reads above) matches a Gated-DeltaNet 3:1 hybrid on LM loss and cross-record recall at iso-FLOP while making deletion exact at O(log N), reset exact, attribution exact, and single-record influence provably bounded — i.e., deletability is (nearly) free if designed in.

**claim_scope:** architecture-causal.

**Mechanism.** L blocks. Writer stack (blocks 1..L_w): record-blocked sliding-window attention (window w, masks never cross record boundaries) plus optional within-record GDN whose state resets at record boundaries; no path from the memory band. Write head at block L_w: k_t^h = norm(W_k^h h_t), v_t^h = W_v^h h_t, alpha_t^h = sigmoid(w_a^h . h_t)^{1/tau}, beta_t^h = sigmoid(w_b^h . h_t), H heads. Memory band: S_t^h = S_{t-1}^h alpha_t^h (I - beta_t^h k_t^h k_t^{hT}) + beta_t^h v_t^h k_t^{hT}; per-record affine factors (A_D^h, B_D^h) kept in a segment tree. Reader stack (blocks L_w+1..L): record-blocked SWA + FFN plus R >= 2 memory-read sublayers y_t = sum_h W_o^h S_{<=t}^h phi(q_t^h) — reads may include the current record's own prefix because its writes come from lower blocks at positions <= t (read-after-write is causal; the two-forward-pass audit verifies it). Training: packed long documents chunked into 512–1024-token segments with segment masks so the band is the only long-range channel and gets used; standard next-token loss. Deployment: segment = record/document/turn. Deletion: S <- S_{j-1} A_{j+1:N} + B_{j+1:N}; reset: S <- 0; attribution: suffix sweep; influence bound: ||Delta y|| <= (||S_{j-1}|| ||A_{D_j} - I|| + ||B_{D_j}||) ||q|| because later compositions are non-expansive, and ||B_D||_F <= sum_t beta_t ||v_t|| is clippable per record. The reader's activations for later records depend on earlier records, but they are not persisted across segments (only S and the current segment's KV are), so everything that persists is exactly deletable. A commutative variant (ridge sufficient statistics, MesaNet-style read) is an arm, not the main claim.

**What is new (delta vs three closest priors).**
1. vs Memorizing Transformers (https://arxiv.org/abs/2203.08913, ICLR 2022 spotlight; abs read): a non-parametric kNN memory of past (k,v) at one layer is exactly deletable by entry removal but grows O(N) bytes and its keys in the original design are computed with XL-style access to earlier segments; we keep a fixed-size compressive band, make the write path provably record-independent, and add the exclusion algebra and attribution — with the kNN memory as the iso-bytes control that decides whether compression of a deletable memory is worth anything.
2. vs MoNe (https://arxiv.org/abs/2608.17616, 2026-08-18; abs read): MoNe attaches a fast-weight memory to a frozen transformer, reads segments with layer-localized sequential gradient updates (order-dependent, so deletion needs replay) and reports no deletion/reset; we train the band from scratch with an order-associative update whose exclusion is exact, and we measure the price of read-free writes against the read-during-write alternative.
3. vs Infini-attention (https://arxiv.org/abs/2404.07143, 2024; abs read) and Block-Attention (https://arxiv.org/abs/2409.15355, ICLR 2025; abs read): Infini-attention writes and reads its compressive memory in every block from the same residual stream (non-addressable); Block-Attention encodes RAG passages independently for KV reuse but has no learned cross-record state. The writer/reader split with a single deletable band between them is the new factorization.
Also positioned against 2607.27539 (§6 future work; retrofit on frozen Gemma 3, not from scratch), MUNKEY (2603.15033; vision, external keys), E2-TTT (2608.21308; from-scratch TTT layer with read-during-write chunks), FwPKM (2601.00671; chunk GD on slots), Naju (https://arxiv.org/abs/2607.21000, 2026-07-23; abs read — "independent retention and writing" decouples the forget gate from the write *gain* to escape |r| + w <= 1, but its write inputs still come from the state-shaped residual stream; a gate-geometry prior, not write-input independence), GradMem (https://arxiv.org/abs/2603.13875, ICML 2026, v2 2026-05-29; abs read — compressive memory in a "context removal" setting written by per-sample test-time gradient descent on prefix memory tokens with frozen weights; iterative, order-dependent, no deletion/reset; a natural "loss-driven writer" comparator arm for the band), the 300M Infini-attention pretraining probe (https://arxiv.org/abs/2512.23862, 2025-12-29; abs read — retrieval degrades under repeated compression yet stays up to 31% above baseline at 16K; the expected failure profile of a compressive band), and the production 3:1 hybrids (Qwen3.8-Next 2608.30320, K3 2607.24653) which are the parity target.

**Falsifiable predictions** (60M/1.0B tokens and 135M/1.5B tokens, document-masked FineWeb-Edu, 3 seeds at 60M).
- P1: LM loss gap between the read-free band model and the iso-FLOP GDN 3:1 hybrid <= 0.02 nats at both scales.
- P2: cross-segment S-NIAH-1 at 4x training length (needle in an earlier segment): within 5 pts of the GDN hybrid and >= 60 pts above SWA+sinks (which has no cross-segment channel); cross-segment MQAR within 5 pts.
- P3: two-hop cross-segment chains: with R = 2 read sublayers within 8 pts of the GDN hybrid; with R = 1 at least 20 pts worse than R = 2 (chained reads need depth) — an internal consistency check.
- P4: the price of the constraint: the ablation whose writer *does* read the band (Infini-style) beats the read-free model by <= 3 pts MQAR and <= 0.01 nats; a gap >= 10 pts means deletability is expensive.
- P5: deletion on the read-free model equals replay to <= 1e-5 relative (fp32 state) with locality change <= 0.5 pt; on the GDN hybrid the static-subtract receipt deviates >= 10% (reproducing 2607.27539 at small scale).

**Kill conditions.** LM gap > 0.05 nats or cross-segment recall gap > 15 pts at both scales after per-arm HP search at the smallest rung; or the exact kNN memory arm dominates the band at equal memory bytes (then deletable memory should simply be an exact store with entry removal, and the compressive band has no reason to exist); or the two-forward-pass audit finds a leak the design cannot remove.

**Cheapest decisive pilot.** Phase 0 (CPU): fp64 oracle for the band algebra and receipts; synthetic MQAR/2-hop generators; causality self-tests on a 2-layer toy. Phase 1 (~16 GPU-h): 60M-parameter arms x 3 seeds x 1.0B tokens (about 0.67 GPU-h each at a conservative 1.5e14 FLOP/s): (a) GDN 3:1 hybrid (fla 0.5.2 kernels), (b) SWA+sinks only, (c) SWA + exact kNN memory at block L_w (iso-bytes), (d) read-free delta-rule band (R = 2), (d') R = 1, (e) read-free commutative ridge band, (f) writer-reads-band ablation; plus 135M x 1.5B tokens for (a) and (d), one seed (about 4.4 GPU-h); 48-config HP search at 20M for (a) and (d) (about 1 GPU-h) with the full >= 256-config bar (2608.11859) deferred to the moonshot stage. pilot_gpu_hours: 16. Moonshot stage (not in the pilot): 340M and 1.3B on 15B tokens (about 50 and 200 GPU-h), then a local retrofit of the band into `qwen3.5-4b` (insert at L_w, train band + reader LoRA on 2–5B tokens) evaluated on LongMemEval/LoCoMo with right-to-be-forgotten deletion requests and receipts.

**Controls.** Arms (a)–(f) at iso-params and iso-FLOP; SWA+sinks (2608.28444 mandate); QED and MARCH as interference/recall baselines at the recall tasks (synthesis mandate); Tail-Replay and DASC as state-summary comparators if any compact-state claim is made; startlux/Massive-Activations 340M/1.3B GDN hybrids (2608.12149) as released reference points for the 340M stage; two-forward-pass prefix-invariance audit; generation-based exact match with SWA-covered fraction reported; length-dependent curves; paired clustered SEs.

**kevin_advantage.** 8xH100 with fla >= 0.5.2 kernels, the digest-pinned Slurm/checkpoint harness (SIGUSR1-resumable long runs), and the program's existing causality doctor. No unique data asset — FineWeb-Edu, RULER and synthetic MQAR are public; parallel data only enters through an optional cross-lingual write/read probe.

**collision_risk: medium.** Compressive-memory hybrids and TTT layers are dense; nobody found trains a from-scratch hybrid with a memory-free writer for deletability; 2607.27539 §6 points this way for retrofits; the arXiv query for compressive-memory hybrids with explicit write/read paths returned a 429 (coverage gap, §5).

**Monitorability and safety.** Every band read is attributable to records (exact leave-one-out), a monitor channel for "which stored items drove this action"; no effect on CoT; deletion certificates are scoped to persisted test-time state. Data: public pretraining data; synthetic probes.

**Negative-result value.** A quantified "price of deletability" (nats and recall points at 60M–135M) does not exist anywhere; if the exact kNN store wins at equal bytes, the field learns that deletable memory should not be compressive; if the constraint costs > 15 pts, right-to-be-forgotten for agent memory must remain a replay-cost problem.

**targets_gaps:** G7, G8, G12.

## 3. Candidate 3 (medium) — `typed-influence-ledger`

**Claim.** On a read-free band, channel-typed write policies (trusted records: full gated delta rule; untrusted records: additive, no-erase, norm-capped writes) give a provable bound on the total influence of untrusted channels on every memory read, and exact leave-one-out attribution detects broad-influence (trigger/DoS) poisons and enables exact reversal — while, as pre-registered, it cannot distinguish plainly false facts from true ones.

**claim_scope:** attachment-capability.

**Mechanism.** Each ingested record D carries a channel type c(D) in {system, user, tool, retrieved, other-agent}. Write policy pi_c: trusted types use (A_t, b_t) as in §0; untrusted types set A_t = I (alpha = 1, no erase term) and write B_D = sum_t beta_t v_t k_t^T with a per-record clip ||B_D||_F <= C_c and a per-channel budget sum_{D in c} ||B_D||_F <= Gamma_c (enforced by rescaling beta). Because every later composition A is non-expansive, for any future read with ||q|| <= 1: ||y(S_N) - y(S_N^{(-c)})|| <= sum_{D in c} ||B_D||_F <= Gamma_c, and for one untrusted record <= C_c; untrusted records cannot erase trusted content by construction. Attribution: suffix sweep gives I_D(q) = ||(S_N - S_N^{(-D)}) q|| for every record; detector score(D) = mean_{q in P} I_D(q) / median_{D'} mean_{q in P} I_{D'}(q) over a held-out benign probe set P; records above tau are quarantined and exactly deleted (Candidate 1 algebra). Threat model: attacker controls only untrusted-channel content (tool results, retrieved documents, other agents' messages), not trusted channels or weights. Attack types: (T) trigger backdoor ("when asked about X, answer Y"), (F) plain false fact (2608.21230 style), (E) erase/DoS record maximizing erase mass on trusted memory, (X) cross-lingual: poison in language A, trigger in language B. The bound is at the memory interface; behavioral effects are Lipschitz-bounded only through the reader, so behavior is measured, not certified.

**What is new (delta vs three closest priors).**
1. vs "Utility Under Attack" (https://arxiv.org/abs/2608.21230, 2026-08-21; abs read): 1.2% plain false assertions drop LongMemEval accuracy 0.850 -> 0.300; a four-stage content screen rejects 0/360 poisons; provenance ranking is indistinguishable from no defense (p = 0.80); they propose bounded occupancy at retrieval for a *text* memory. We move the defense into the write path of a *parametric* fast-weight memory with a provable influence bound, add exact attribution/reversal, and pre-register that false facts remain undetectable by influence.
2. vs "Test-Time Training Undermines Safety Guardrails" (https://arxiv.org/abs/2605.22984, 2026-05-21; abs read): threat models for LoRA-style TTT (ASR@10 95%/93%) with a provider-side perplexity-shift detector; no fast-weight layers, no channel typing, no deletion. Ours is the first poisoning study of architectural fast-weight memories found under §5 coverage, with LoRA-TTT as the comparator arm.
3. vs CaMeL "Defeating Prompt Injections by Design" (https://arxiv.org/abs/2503.18813, 2025; abs read): a system layer that keeps untrusted data out of control flow with capabilities (77% AgentDojo tasks solved with provable security); it never touches model state. Ours types the *memory write* inside the architecture so untrusted content can add associations with bounded influence but can never erase; CaMeL-style exclusion (untrusted data never enters memory) is the lossy comparator.
Also positioned against AgentPoison (2407.12784) and MINJA (2503.03704) (text-memory/RAG poisoning; abs read), MemGauge (2608.30177; stage-wise exposure of text memory; abs read), TwinKV (2608.27128; leave-one-out causal probe on KV caches, approximate; abs read), influence functions (1703.04730; approximate, training-set level; abs read), WriteSAE (https://arxiv.org/abs/2605.12770, v4 2026-05-19; abs read — rank-1 atoms over the matrix writes of GDN/Mamba-2/RWKV-7 with a cache-level steering intervention; interprets *what* a write encodes, not *which record* a read depends on, and has no deletion or leave-one-out), and Deep Partition Aggregation (2006.14768; abs read) — a considered-and-rejected variant: partition-aggregation certificates need every shard to be able to answer, which associative memory violates (a fact stored in one shard is suppressed by median aggregation), so the DPA import fails here and is recorded as such.

**Falsifiable predictions** (Qwen3-0.6B-Base + Candidate 1 memory, or the 60M Candidate 2 model; 200 benign records, 20 poisons per type).
- P1: influence-detector AUROC >= 0.90 for T and E poisons vs benign salient records, and <= 0.60 for F (its limitation is part of the claim).
- P2: additive-capped untrusted mode with C_c = 0.1 x median benign ||B_D||_F cuts T-ASR from >= 80% (undefended, if the fast weights carry the trigger) to <= 10%, leaves trusted-record recall within 1 pt, and costs <= 10 pts recall on benign untrusted records; E-ASR is 0 by construction with measured erase mass reported.
- P3: exact deletion after a flag restores next-token KL <= 1e-6 nats to the never-stored model on 1,000 probe prompts; gradient-ascent unlearning of the same fast weights leaves >= 0.05 nats residual and >= 2 pt locality damage.
- P4 (cross-lingual, Kevin asset): X-ASR is either >= 50% of same-language ASR (the memory stores meaning) or <= 10% (surface); both bands pre-registered, either is informative for G2.

**Kill conditions.** Undefended T-ASR < 10% — the fast-weight memory does not carry context-borne triggers (a scoping negative consistent with LongVU-TTT's "aggregate rather than remember"); or the cap needed to bring T-ASR <= 10% costs > 30 pts recall on benign untrusted records (the typed budget is useless).

**Cheapest decisive pilot.** Phase 0 (CPU): verify the influence bound numerically on fp64 factor lists including adversarially constructed erase records; detector calibration on synthetic memories. Phase 1 (~4 GPU-h): build the fast-weight poisoning benchmark on `qwen3-0.6b-base` with the Candidate 1 memory (or the Candidate 2 60M model if trained): T/F/E/X attacks, defenses {none, content screen (LLM judge), provenance down-weighting, typed budgets at C in {0.5, 0.1, 0.02} x median, influence flag + exact deletion, gradient-ascent unlearning, CaMeL-style exclusion}; report ASR, benign recall, AUROC, post-deletion KL. X uses FLORES-200 translations (Kevin's production parallel data adds domain terminology). pilot_gpu_hours: 4. Optional Tinker arm: LoRA-TTT attack comparator on Qwen3.5-4B (2605.22984 threat model), token budget ~20M.

**Controls.** No-defense; content screening and provenance ranking (2608.21230); MemGauge-style stage-wise exposure reporting (2608.30177); LoRA-TTT jailbreak arm (2605.22984); CaMeL-style exclusion; never-stored oracle; gradient-ascent unlearning at matched compute; validity-aware judging for degenerate outputs (2605.22984); prefix-invariance audit.

**kevin_advantage.** The harness's replay/audit log gives clean paired attack/defense estimands; parallel translation data makes the cross-lingual transfer arm cheap (FLORES suffices for the pilot). Otherwise modest.

**collision_risk: low–medium** (reported as "low" in the structured object with this caveat): no poisoning or defense paper targets architectural fast-weight layers in LMs under §5 coverage (arXiv query for poisoning/backdoor/injection x TTT/fast weights/linear attention/neural memory returned only TTRL amplification 2603.15417 and two 2020 items); agent-memory poisoning (text) and prompt-injection-by-design are active and adjacent, so the framing could be occupied within months.

**Negative-result value.** If fast weights do not carry triggers, the TTT poisoning threat is scoped to LoRA-style TTT (2605.22984); if influence cannot separate triggers from salient benign facts, attribution alone cannot defend and typed budgets are the only lever; the cross-lingual arm answers G2's "meaning or surface" question for one memory class either way.

## 4. Considered and rejected within this angle

- Partition-aggregation (DPA/SISA-style) certificates for associative memory: recall needs the item in a majority of shards, robustness needs poisons in a minority — contradictory; rejected (recorded above).
- Differential-privacy-style insensitivity to a single record: incompatible with exact recall of that record by definition; poisoning "resistance" must be attribution + reversibility, not insensitivity.
- Rollback by inverting the delta rule (Sherman–Morrison undo of the suffix): exact per step but conditioning blows up as beta -> 1 or alpha -> 0, the same limit Reversible RNNs (1810.10999) hit with forgetting gates; exclusion via forward composition never inverts and is preferred.
- Re-proposing better erase gates, surprise gating, or coded state: occupied/rejected per the brief; not touched.
