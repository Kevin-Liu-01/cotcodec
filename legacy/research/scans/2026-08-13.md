# Frontier Memory Research Delta — 2026-08-13

**Cutoff:** 2026-08-13  
**Scope:** semantic and episodic memory, active/inactive residency, temporal
graphs, procedural memory, learned controllers, latent memory, causal credit,
interference, safety, OSS systems, and contained execution  
**Source ledger:** `research/memory-sources.yaml`  
**Prior full scan:** `research/scans/2026-08-11.md`

## Decision

The broad ideas are occupied. A new vector store, graph, active/archive split,
reflection loop, learned CRUD policy, future-use predictor, procedural-memory
distillation method, proactive injector, reconstruction policy, or generic
memory-interference benchmark is not a defensible standalone contribution.

The surviving claim is deliberately narrow:

> No direct prior found through 2026-08-13 combines prospective
> known-propensity first-eligible-use assignment of persistent semantic
> memories, executable downstream utility, cross-fitted population estimation,
> paired deterministic audit, and a strictly past-only deployment gate.

Even this is a hypothesis and experimental-design contribution, not a proven
mechanism. Paired deletion effects are occupied by CommitKV; query-time causal
selection is occupied by Causal Memory Intervention; future utility and
prediction-error retention are occupied; generic interference is occupied by
Controlled Memory Interference; same-state counterfactual CRUD credit is
occupied by Memory-R2; executable local/global verifier credit is occupied by
VerMem; online operation selection is occupied by MemCon; and randomized
memory ablation for certified poisoning defense is occupied by SMSR.
The residual is the prospective population trial and the policy learned from it.

### Portability is infrastructure, not the research claim

[memorywire](https://arxiv.org/abs/2606.01138) already defines a vendor-neutral
remember/recall/forget/merge/expire protocol with multiple backend adapters,
routing, and governance. Its [Apache-2.0 implementation](https://github.com/mthamil107/memorywire)
is the appropriate wire/conformance baseline when crossing memory backends.
[Portable Agent Memory](https://arxiv.org/abs/2605.11032) further proposes a
Merkle-DAG state package spanning episodic, semantic, procedural, working, and
identity memory with scoped rehydration. No public SDK was located for the
latter at this cutoff, so its reported pilot is a design prior, not executable
evidence. [ToolAtlas](https://arxiv.org/abs/2607.11126) also reports
execution-verified provider-side tool memory that transfers across agents and
frameworks; its paper-declared repository returned 404 at this audit. A
portable strap-on layer may enable experiments, but it is not the novel
mechanism.

### Cost and evaluation changed materially

[Total Recall at What Cost?](https://arxiv.org/abs/2608.11879) reports that
system-internal serving behavior makes estimated cost inaccurate and that some
systems do not break even within a 400-turn horizon. Every trial must therefore
record actual construction, service, context, maintenance, storage, and model
costs and report a measured break-even horizon. Token count alone is not enough.

[MemoryData](https://github.com/OpenDataBox/MemoryData) evaluates memory as four
modules—representation/storage, extraction, retrieval/routing, and
maintenance—and exposes substantial workload dependence. It is a useful
integration and ablation reference, but its heterogeneous method wrappers do
not by themselves guarantee matched models, prompts, budgets, or versions.

[Ground Truth First](https://arxiv.org/abs/2607.21962) predefines validity
intervals, volatility, source channels, and answers before rendering the
longitudinal interaction. Its MIT implementation is a mandatory generator
control; synthetic data generated from a hidden label shortcut is not evidence
for a deployable policy.

[SF-AMS](https://arxiv.org/abs/2607.22562) adds a required strategic-forgetting
control based on temporal, redundancy, semantic, and entity-consistency utility.
[GateMem](https://github.com/rzhub/GateMem) adds 91 synthetic multi-principal
episodes with 2,218 hidden checkpoints for authorized utility and explicit
deletion; it is a governance/safety test, not a quality oracle.
[ENPMR-Bench](https://aclanthology.org/2026.findings-acl.2080/) adds proactive
emotional-need memory retrieval, but no official code or data artifact was
located at this cutoff.

### Required persistent-system doctor

Each native system must remain alive across:

```text
user A write -> search -> update -> search -> delete -> negative search
user B cross-tenant negative search
process restart -> expected state recovery
purge user A -> backend-level absence proof -> second idempotent purge
poison write -> delayed trigger -> repair -> negative delayed trigger
```

The harness must verify backend state directly. An adapter returning
`{"purged": true}` is not evidence of deletion. Logical `user_id`, bank,
namespace, or group fields are not authorization proofs.

## Experimental program

### Direction A — prospective first-use causal memory

Randomize one eligible persistent semantic item to `SERVE` or `HOLDOUT` before
first service. Commit assignment before actor execution. Estimate task success,
tool correctness, latency, tokens, and safety with known propensity and
cross-fitted AIPW. On deterministic self-hosted audit rows, restore the exact
snapshot and run the opposite arm.

Primary comparison:

```text
value(frozen past-only causal gate)
  - value(strongest matched noncausal learned control)
```

Controls: no memory, full/sliding context, FIFO/LRU/LFU/random, raw-log
agentic BM25 in the ReFind style, BGE top-k, hybrid retrieval, temporal graph,
next-use, prediction error, AttriMem, observational future utility, query-time
CMI, and matched RoMeRL-style credit. Graph arms must additionally face
ProGraph and the UnifiedMem graph-vs-flat configurations; memory-depth routing
must face Router-Mem/ERSkill-style controllers; expiry must face ScrubJay-MEM;
active/inactive and proactive arms must face Unified Memory Agent, RecMem, and
Remember When It Matters. SMSR is a randomized-ablation safety control, not a
substitute for the first-service population estimand.

Kill if AIPW misses paired ATE by more than 0.05, per-arm support fails, the
past-only gate fails suffix permutation, ReFind-style raw-log search or
ProGraph matches a more expensive structured arm at equal cost, or the
strongest noncausal control ties the causal gate within the registered
three-point margin.

### Direction B — randomized saturation effects

This is not “memory interference.” Randomize the served saturation and
composition of competing persistent items under known propensities. Estimate
redundancy, complementarity, contradiction, and authority interactions on
executable tasks. Controlled Memory Interference supplies the simpler labeled
diagnostic baseline.

Kill if positivity fails, interaction intervals concentrate around zero, or
relationship labels explain all benefit without randomized saturation.

### Direction C — write, serve, and retain decomposition

Treat write admission, first service, and continued retention as separate
sequential treatments. Do not call all three “memory value.” Pre-register
eligibility and use sequential estimators only if treatment-induced eligibility
and overlap are defensible.

Kill if stage effects are not identifiable or the decomposition adds no policy
