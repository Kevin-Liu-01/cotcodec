# Frontier Memory Scan — 2026-08-15

## Bottom line

The strict same-day arXiv query returned no submission dated 2026-08-15 in
cs.AI, cs.CL, cs.IR, cs.MA, or cs.LG at the scan cutoff. Repository search did
surface nineteen omitted open-code systems across five bounded waves. They are useful
chiefly because they sharpen the experimental boundary:

1. a committed high LongMemEval score can still be invalid evidence for
   distractor-haystack retrieval;
2. an append-only graph store needs crash and erasure tests before an actor
   benchmark; and
3. an API named archive/promote/demote is not active/inactive memory if it only
   returns a label;
4. hot/cold prompt views are context injection, not durable residency; and
5. a fixed long-form context allocator is a compaction control, not a memory
   lifecycle;
6. an episode hierarchy must be separated from extraction and reranking;
7. human-approved decision status is governance, not autonomous paging;
8. a one-way archive flag is not a recoverable inactive tier;
9. a small matched harness can expose costs while remaining scientifically
   underpowered and unlicensed; and
10. an honest strategy-memory null is more valuable than a confounded raw gain;
    and
11. a bounded working set over a durable store is a credible pager candidate,
    but source structure and component tests are not an end-to-end lifecycle result;
12. branch, snapshot, merge, and rollback semantics are transactional lifecycle,
    not active/inactive paging;
13. a named visibility tier and inherited scope are not residency transitions;
14. a typed graph CLI is a systems control until traversal beats an identical
    flat representation; and
15. a paper-linked open harness is not result evidence when its claimed result
    bytes are absent from both the evaluated tag and current tree;
16. an event-sourced execution graph is a replay substrate, not evidence that a
    semantic-memory graph improves an agent;
17. explicit cold-to-warm restoration is a lifecycle control, not a learned
    bidirectional pager, and a retracted benchmark headline is negative evidence;
18. copy-on-write vector branches isolate alternative states but do not create
    active/inactive residency; and
19. a standalone Hermes provider belongs in a separate admission cohort rather
    than being retroactively added to a sealed bundled-provider roster.

ASTRA is the first same-day source to implement the required bidirectional
working-set shape: bounded active residents, eviction without durable deletion,
and later retrieval-driven re-admission. Two contained component runs reproduced
its pure window/retrieval/guard behavior. The subsequent native H100 lifecycle
cell (Slurm job 269) executed eviction, durable re-admission, forced database
restart, and isolation twice, but failed its clean-store identity gate: equal
recall totals reinforced different tied records. A **deterministic native
bidirectional pager result therefore remains absent**. The current revision is
actor-blocked before any memory-quality spend. No source changes the narrow CMHT
novelty statement.

## Active/inactive memory conclusion

The operational definition remains:

- **active**: resident in the bounded serving state used without a new archive
  lookup;
- **inactive**: retained outside that state but recoverable by an explicit,
  metered read;
- **promotion/demotion**: a durable state transition that changes serving
  eligibility and survives restart;
- **bidirectional paging**: both directions occur under a registered policy,
  with bytes, reads, writes, maintenance, and model calls charged.

Labels, relevance scores, hot/warm/cold names, compressed representations, and
separate stores are insufficient. Every candidate must prove exact movement,
restart, no cross-session bleed, purge, and both-direction behavior before it
enters the H100 actor matrix.

ASTRA satisfies the source-level shape and demonstrates the operational
eviction/re-admission/restart path, but fails deterministic persistent recall
state. Its admission changes the program from “no concrete candidate” to “one
credible mechanism with a reproduced native blocker,” not to “bidirectional
paging works.”

## Resulting program decision

Today adds no new flagship direction. It strengthens four rules:

1. benchmark artifacts must bind the task source role, not merely a dataset
   name;
2. storage systems must pass lifecycle and erasure doctors before quality
   comparison; and
3. active/inactive memory is an executable residency transition, not marketing
   vocabulary; and
4. source-level paging only earns H100 time after native eviction, re-admission,
   restart, isolation, and purge are frozen as executable evidence.

The research program remains: establish strong flat retrieval floors, isolate
graph structure over identical information, admit lifecycle mechanisms through
contained CPU doctors, and use H100s only for frozen-model actor comparisons
whose inputs and mechanisms are already sealed.
