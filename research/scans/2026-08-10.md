# Frontier Research Scan — 2026-08-10

**Cutoff:** 2026-08-10
**Scope:** architecture, portable adaptation, agent harnesses, evaluation, and
compute operations relevant to CoTCodec
**Detailed synthesis:** `research/frontier-systems-program-2026-08-10.md`

## Executive summary

The architecture search should not lead with another generic attention or
linear-recurrence replacement. That space is already occupied by Mamba-2,
Gated DeltaNet, Kimi Linear, test-time-learning layers, recurrent-depth models,
and diffusion language models. A second-wave collision audit demoted **Coded
Delta Memory**: error-correcting associative memories and coded KV state are
direct precedents, while coherent semantic overwrites may yield no syndrome.
**Causal Memory Holdout Trials** is now the closest decisive mechanism pilot:
randomize one memory item's serving eligibility, audit the propensity estimator
against paired replay, and learn a past-only policy. **Translation-Equivariant
Byte Boundaries** is the architecture-level moonshot.
**Portable Sidecar Update Dynamics** remains the PorTAL-like bet only after
narrowing: learned optimizers and transferable update rules occupy the broad
claim, so the possible residue is task-conditioned sidecar state with task-blind
alignment and a held-out task–operator pairing test.

PorTAL is a useful factorization, not yet evidence for literal train-once
adaptation: its released target-base alignment still uses target-task labels,
its public evaluator takes dataset prefixes, and it lacks a held-out test split.
SR-TTT v2 remains an important negative signal: corrected causality and
off-by-one evaluation removed the reported exact-memory gains. Memory pilots
must therefore test startup causality and generation exact match before scale.

The repo itself remains the immediate constraint. FieldTheory independently
ranked a real executable agent loop, deterministic canary oracles, and paired
regression gates above new workflow abstractions. The audited 8×H100 host has
Docker binaries but no user access to the daemon and no visible Slurm/Pyxis
stack. Rootless Podman built and CPU-smoked the research image, but GPU
passthrough is unavailable without NVIDIA CDI/OCI hooks. Slurm provenance and
GPU allocation tests remain blocked on cluster administration.

## High-priority signals

### 1. PorTAL portable adaptation — score 5/5

- **Source:** [Ramp report](https://labs.ramp.com/research/portal-portable-task-adaptation/),
  [public code](https://github.com/ramp-public/portallib)
- **Signal:** task latent + shared canonical core + base alignment can generate
  ordinary LoRA weights across model families.
- **Caveat:** released alignment uses target-task labels; validation is reused
  for model selection/reporting; prefix evaluation creates dataset-composition
  bias ([issue #27](https://github.com/ramp-public/portallib/issues/27)).
- **Action:** reproduce the released recipe exactly, then retrain under a newly
  sealed split. Treat portable update rules as high-collision hypotheses, not
  the automatic next step.

### 2. Kimi Linear / KDA production hybrid — score 5/5

- **Source:** [official code](https://github.com/MoonshotAI/Kimi-Linear)
- **Signal:** linear recurrence plus periodic global attention has crossed from
  toy architecture into a serious long-context implementation.
- **Action:** treat static attention/recurrence mixtures as occupied. Test
  capabilities KDA lacks: explicit interference syndromes, edit semantics, or
  budgeted operator routing.

### 3. SR-TTT corrected evaluation — score 5/5

- **Source:** [SR-TTT v2](https://arxiv.org/html/2603.06642v2)
- **Signal:** the revised paper retracts original memory claims after finding
  off-by-one and noncausal leakage; corrected paired trials report zero exact
  matches.
- **Action:** add mandatory startup perturbation, exact generation, and
  storage/addressing/readout decomposition to all memory experiments.

### 4. Claude-of-Duty loop evidence — score 4/5

- **Source:** [repository and assessment](https://github.com/mshumer/Claude-of-Duty)
- **Signal:** fresh critics and deterministic visual/performance checks help,
  but parallel directory waves increased integration defects. A sequential
  owner for coupled concerns produced the largest improvement.
- **Action:** use independent agents for discovery/disproof only; serialize
  synthesis. Adopt finite exits and deterministic readiness gates.

### 5. Byte patches and multilingual concept spaces — score 4/5

- **Sources:** [Byte Latent Transformer](https://arxiv.org/abs/2412.09871),
  [shared multilingual concept spaces](https://aclanthology.org/2026.eacl-long.145/)
- **Signal:** tokenizer-free dynamic patches and cross-language shared
  representations create a tractable bridge to Kevin's translation advantage.
- **Action:** pilot translation-equivariant byte boundaries at matched patch
  count and FLOPs; reject if a simple consistency loss performs equally well.

## Medium-priority signals

- **FieldTheory harness findings — score 3/5.** Four bookmark-seeded runs
  independently prioritized the executable agent-loop spine, deterministic
  canary fixtures, paired regression gates, crash-safe queues, and typed context
  decision receipts. These are high-leverage prerequisites, not architecture
  contributions.
- **Bidirectional plan repair — score 3/5.** Existing diffusion checkpoints make
  partial action-DAG repair testable without pretraining a new language model.
  Equal-wall-time autoregressive repair remains the kill baseline.
- **Causal orchestration graphs — score 3/5.** Event-sourced graph surgery could
  expose interactions among CoTCodec's variables, but causal claims require
  deterministic tool replay and held-out full-rerun validation.

## Rejected or downgraded

- Generic linear attention, static SSM/attention mixtures, surprise-gated
  memory, generic latent loops, diffusion+MoE, Graph RAG, and “more agents” as a
  default were downgraded because of direct collisions or confounding.
- Geometry-compiled PorTAL alignment remains a moonshot until enough open model
  families and weight/activation sketches are available.

## Benchmark and evaluation updates

- Ban benchmark prefix slicing; use full or seeded stratified samples.
- Separate validation used for selection from untouched test reporting.
- Require iso-parameter, iso-FLOP, and iso-wall-time comparisons.
- Report TTFT/TPOT, p50/p95/p99, peak HBM, throughput, and kernel fallbacks.
- Require at least three seeds for interpretation and five near a paper claim.

## Landscape summary

Attention replacement is no longer the useful level of abstraction. The open
questions are what state operations a model can guarantee, how learning rules
port across base geometries, how compute routes among operators, and whether
architecture state is safe, editable, and auditable. This extends rather than
replaces CoTCodec: architecture mechanisms should first be isolated in a small
standalone harness, while the agent harness measures their downstream effects.
