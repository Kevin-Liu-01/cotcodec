# Frontier Memory Scan — 2026-08-14

## Bottom line

No new arXiv submission dated 2026-08-14 was visible in the cs.AI, cs.CL,
cs.IR, cs.MA, or cs.LG feeds at the 12:18 UTC cutoff. The useful delta came
from two places:

1. a bounded backfill of primary work that changes the control and evaluation
   design; and
2. same-day and previously missed open-source systems that are useful controls
   but do not create a new direction.

The memory program should not start with a graph, learned CRUD controller, or
active/inactive pager. The next claim-relevant cell is the simplest strong
inactive-archive floor: MemPalace raw user-session retrieval on the full 500
LongMemEval tasks with the same frozen actor and official semantic judge used
for BM25, dense BGE, and raw-log RRF. Graph, paging, consolidation, and causal
credit cells follow only if they beat that floor under matched budgets.

The narrow Causal Memory Holdout Trial (CMHT) hypothesis survives. This scan
found no direct prior that combines prospective known-propensity assignment of
one retained item at first eligible service, executable downstream utility, an
independent paired continuation from the same pre-service state, and a
cross-fitted deployment gate restricted to write-time covariates. It does not
claim novelty for random ablation, outcome-updated memory utility, memory/no-
memory comparisons, active/archive paging, graph memory, learned CRUD,
proactive injection, consolidation, or counterfactual replay.

These sources add controls, not a new flagship direction. In particular,
generated abstractions, graph traversal, consolidation timing, residency, and

The first GAAMA control remains a deliberately synthetic component contract.
Two fresh network-disabled, read-only, non-root Docker runs produced identical
24-case reports: true graph retrieved 24/24 targets, while flat and shuffled
graph retrieved 0/24; setting PPR weight to zero exactly matched flat retrieval.
It also exposed that the upstream hub-dampening factor is canceled by row
normalization. Evidence `research/evidence/memory/gaama-graph-component-v1.json`
(`cf903e2b...`) establishes only that component contract.

A separate natural held-out control now passes the narrower retrieval question.
The dev split selected PPR weight 0.5; on 1,146 questions from seven untouched
LoCoMo conversations, the true structural graph beat flat BM25 by 2.04
conversation-equal points (95% bootstrap CI [1.25, 2.96], one-sided sign
randomization p=0.0078). It beat the mean of three typed, per-node directed-degree-
preserving shuffled graphs by 2.17 points (95% CI [1.30, 3.20], p=0.0078).
Two fresh contained runs were byte-identical, used zero model, embedding,
network, or GPU calls, and passed exact candidate/degree and zero-weight lexical
controls. The v5 evidence bundle embeds the pinned LoCoMo artifact and reruns
every ranking during validation:
`research/evidence/memory/gaama-natural-graph-v5.json` (`011a2191...`). An
independent harsh review found no remaining P0/P1/P2 defects. This supports only
a raw-dialogue retrieval component; generated semantic nodes, GEL, answer
quality, agent success, amd64 Slurm confirmation, and an H100 actor comparison
remain unrun or blocked.

## Resulting experimental contract

The minimum matched quality matrix is now:

1. no memory;
2. full-prefix ceiling, explicitly unmatched and diagnostic;
3. BM25 raw evidence;
4. dense BGE raw evidence;
5. raw-log RRF;
6. MemPalace raw user-session MiniLM retrieval;
7. flat typed facts;
8. temporal graph using the same extracted facts;
9. graph-free profile traversal;
10. state-role/post-retrieval assembly ablations where the task contains
    updates or conflicts.

Every matched arm gets the same actor, task roster/order, prompt, decoding,
top-k, injected-token limit, context limit, judge, and tuning budget. Charge
construction calls, embedding calls, serialized bytes, retrieval reads,
rendered tokens, maintenance, and p50/p95 latency. Full-prefix remains a
separate ceiling. Graph metadata and consolidation calls are never free.

For longitudinal active/inactive claims, retain PAST-Bench as a later external
pathway test but preserve the SM01 null: its exact restart-equivalence contract
failed. A new attempt must either prove dense within-model exactness before a
family run or preregister repeated stochastic estimation; it may not merge
resumed cold-load blocks into a deterministic claim. A pager must still beat
recency/LRU at K={2,4,8} after charging memory-administration calls. An archive
service that never promotes is not a pager.

The new source admission doctor validates PAST-Bench without executing upstream
code. It binds the Git commit/tree/archive, license and runtime files, exact
category/family/episode counts, every declared task/fixture directory, reference
manifest ordering, fresh-session and persistence-control fields, and the seven
unreferenced update task directories. It reports
`VALIDATED_SOURCE_CONTRACT_NOT_EXECUTION`; the later contained jobs remain
self-attested discovery evidence and their restart divergence is the current
scientific result for that exact cell.

For temporal claims, split failures into bank correctness, retrieval evidence,
post-retrieval assembly, and final answer policy. A graph win is invalid if an
identical flat typed-fact arm or A-TMA-style evidence packet ties it at lower
cost.

## Next contained cell

### Single-load full-500 inactive-archive floor

- Retrieval/freeze: CPU-only offline Docker-under-Slurm, 16 CPU, 32 GB, four
  hours; freeze and seal no-memory, BM25, dense BGE, raw-log RRF, and MemPalace
  selection bundles before actor inference.
- Actor: load Qwen3.6-35B-A3B exactly once, then run all five all-SERVE arms for
  all 500 tasks in a preregistered balanced interleaving, top-4 and at most 256
  injected tokens, on one 2×H100 allocation with a four-hour hard limit (8
  H100-hours). A 10-task-per-arm throughput doctor must project completion
  below 3.5 hours.
- Recovery: any preemption or process restart makes the cell discovery-only;
  the claim report must not combine outputs from a second model-load block.
- Evaluation: separately sealed official LongMemEval semantic judge, then a
  task-paired comparison. Test MemPalace against dense BGE and raw-log RRF with
  exact McNemar plus session-clustered bootstrap and Holm adjustment.
- Kill rule: stop on coverage below 500, valid-action rate below 95%, any
  safety/session bleed, within-load A/A drift, budget/source mismatch, or if
  either simultaneous 95% lower bound for MemPalace is at most zero. A win
  makes it a mandatory floor only; a null rejects raw session retrieval as
