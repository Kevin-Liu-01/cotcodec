## Executive summary

The obvious memory-system directions are occupied. MemGPT/Letta already pages
between active core and inactive archive. Graphiti, Hindsight, Cognee, A-MEM,
and MemOS cover temporal or evolving graphs. Mem0, Supermemory, and LangMem
cover fact/profile extraction, updates, consolidation, and forgetting. AgeMem,
Memory-R1, MemexRL, MemRL, and MemCon learn memory actions or utility. PRIME and
Remember When It Matters study proactive injection. ForesightKV, KVP, and
KVpop use future-derived labels for latent retention. A new vector store,
knowledge graph, active/archive split, learned CRUD policy, proactive reminder,
or future-use predictor is not a credible standalone novelty claim.

The high-value scientific interface is a policy over transitions—write,
activate, retrieve, inject, update, consolidate, expire, and forget—under one
matched task/model/budget/safety harness. The strongest narrow survivor remains
Causal Memory Holdout Trials: prospective known-propensity assignment at first
eligible use, executable downstream utility, paired deterministic replay,
cross-fitted AIPW, and a strictly past-only deployment gate. Query-time causal
intervention is now a direct required control.

The evaluation plan should combine deterministic 20–40-step memory-to-tool
episodes with sealed public external tests. LongMemEval provides extraction,
cross-session synthesis, temporal updates, and abstention. MemoryAgentBench
decomposes retrieval, test-time learning, long-range understanding, and
selective forgetting. Mem2ActBench is the most relevant public substrate for
exact memory-dependent tool action. LongMemEval-V2 is a later long-horizon
external-validity cell, not the first pilot.

Safety cannot be deferred. AgentPoison, query-only memory injection, sleeper
memory poisoning, and later systematic studies show that persistent memory
creates delayed, cross-session attack surfaces. A memory item can improve the
current task while increasing later poisoning or leakage risk.

## High-priority signals

### 1. Prospective first-use causal credit — score 5/5

- **Sources:** [Causal Memory Intervention](https://arxiv.org/abs/2605.17641),
  [Fine-Mem](https://aclanthology.org/2026.acl-long.900/),
  [memory-management impact study](https://aclanthology.org/2026.acl-long.27/)
- **Signal:** query-time interventions and observational/deletion credit are
  occupied, but no direct prior found in this scan combines prospective
  first-eligible-use randomization, logged propensity, executable task utility,
  paired replay, and a past-only gate.
- **Action:** preserve the narrow CMHT wording; make query-time intervention,
  next-use prediction, and observational utility matched controls.

### 2. Active/core versus inactive/archive is a residency axis — score 5/5

- **Sources:** [MemGPT](https://arxiv.org/abs/2310.08560),
  [MemexRL](https://arxiv.org/abs/2603.04257),
  [Letta](https://github.com/letta-ai/letta)
- **Signal:** active memory is context-resident and expensive; inactive memory
  is externally retained and retrieval-dependent. Importance and residency are
  not the same thing.
- **Action:** factor store, serve-now, and retain-for-later rather than comparing
  opaque systems only.

### 3. Temporal graphs are a required control, not the paper — score 5/5

- **Sources:** [Graphiti/Zep](https://github.com/getzep/graphiti),
  [A-MEM](https://arxiv.org/abs/2502.12110),
  [AriGraph](https://arxiv.org/abs/2407.04363),
  [APEX-MEM](https://aclanthology.org/2026.acl-long.749/)
- **Signal:** entities, relationships, provenance, episodes, validity windows,
  contradiction, and evolving note graphs are all occupied mechanisms.
- **Action:** compare temporal graph, flat event log, BM25/vector retrieval, and
  extract-and-update facts at equal serialized bytes, construction calls,
  retrievals, and rendered tokens. Kill the graph if BM25 ties it.

### 4. Learned memory CRUD and timing are crowded — score 5/5

- **Sources:** [AgeMem](https://arxiv.org/abs/2601.01885),
  [Memory-R1](https://aclanthology.org/2026.acl-long.583/),
  [MemexRL](https://arxiv.org/abs/2603.04257),
  [MemRL](https://arxiv.org/abs/2601.03192),
  [Remember When It Matters](https://arxiv.org/abs/2607.08716)
- **Signal:** store/read/update/summarize/delete, runtime value learning, and
  proactive reminders have direct precedents.
- **Action:** train an external controller only after causal targets and simple
  controls are valid. Do not describe controller training as architecture novelty.

### 5. Memory safety has delayed outcomes — score 5/5

- **Sources:** [AgentPoison](https://arxiv.org/abs/2407.12784),
  [query-only memory injection](https://arxiv.org/abs/2503.03704),
  [Hidden in Memory](https://arxiv.org/abs/2605.15338),
  [systematic memory-poisoning study](https://arxiv.org/abs/2606.04329)
- **Signal:** save-path and serve-path failures can remain dormant across
  sessions, and filters have material false-positive/false-negative tradeoffs.
- **Action:** estimate immediate task benefit and later attack risk together;
  require PII canaries, deletion, permission change, and cross-user probes.

## Open-source baseline decision

Mandatory core systems:

1. Mem0 OSS — low-burden fact/profile memory.
2. Graphiti — temporal graph with provenance and validity.
3. LangMem/LangGraph Store — transparent hot-path/background policy library.
4. Hindsight — retain/recall/reflect and graph-plus-profile pipeline.

Separate system-level arm:

5. Letta/Letta Code — agent self-manages and rewrites memory, so it cannot be
   treated as a drop-in retrieval backend.

Static retrieval controls:

6. HippoRAG; GraphRAG only if construction budget permits.

Exploratory secondary systems:

7. Cognee, MemOS, Supermemory, and A-MEM.

Every system is pinned in `research/memory-sources.yaml`. Unresolved repository
licenses block reuse, not literature comparison. Managed product claims are not
assumed to describe their open-source configurations.

## Benchmark and methodology updates

- Add deterministic active-core, inactive-archive, temporal-graph, and
  proactive-tool strata with exact oracles.
- Use one candidate item per pilot episode; multi-item interference changes the
  estimand and comes later.
- Split by generator/template/entity/graph/update/delay families, never rows.
- Freeze the base model, extractor, embedder, prompt, decode config, top-k,
  injected-token cap, storage bytes, and tuning trials.
- Record raw model and judge outputs for public QA benchmarks, but keep the
  deterministic tool evaluator as the primary internal endpoint.
- Counterfactually rename entities and swap answer values to detect pretrained
  answer leakage.
- Charge graph construction, reflection, consolidation, proactive calls, and
  index growth in both amortized and per-task views.
- Require engine-owned snapshots, RNG state, tool tapes, prompt hashes, and
  event-by-event branch comparison; adapter self-attestation is insufficient.

## Rejected or downgraded

- A new memory graph, active/archive split, reflection loop, or semantic profile.
- Generic learned CRUD, proactive memory, future-use prediction, or RL retrieval.
- Cross-paper leaderboard comparison without matched model/answerer/judge/configuration.
- LoCoMo as the sole endpoint.
- Tmux as a checkpoint or scheduler substitute.
