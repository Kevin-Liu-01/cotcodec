A causal decomposition of how a localized right-to-left interface affects a screenshot-driven computer-use agent, run inside one executable desktop benchmark. For one office suite whose tasks, documents, instructions, checkers and operating-system shell all stay in English, a single system-level configuration file sets two factors independently: the application's interface text language (English or Arabic, from the application's own shipped translations) and its layout direction (left-to-right or mirrored, from the application's own direction key). The four cells of this 2x2 differ only in that file. Before any model runs, an executable pilot and a render oracle on the real application check that each switch does only what it should: the direction key mirrors the whole application chrome while documents stay unmirrored, window titles stay byte-identical, the key is pixel-equivalent to the application's environment switch, catalog strings that become document content are found and held fixed (a default sheet-name prefix is pinned, so a checker that reads a sheet by its default name is not broken by translation), and accessibility-tree boxes, shown to be unreliable under mirroring, are replaced by rendered pixels when mirroring is certified. The measurement is a census: every task of the benchmark's office-suite subset that passes fixed eligibility rules (about 106), with no selection on the agent's success, four episodes per task and cell split across two certified agent scaffolds in one serving session. The layout and text main effects sum exactly to the total change. The primary decision is made for these tasks (an interval from episode-level variance) with a dual equivalence margin (5 percentage points absolute and a 15% ratio of solve rates, which never-solved tasks cannot dilute), so a robustness null is reachable (simulated 0.92-0.97 under null effects) and a 15% relative harm is detected with probability 0.85-0.96; a population-level reading with a concentration guard is reported beside it. Task-level moderators (the agent's own click displacement under mirroring, overlap between instruction words and interface labels, counts of rendering defects) test which route carries any effect.
