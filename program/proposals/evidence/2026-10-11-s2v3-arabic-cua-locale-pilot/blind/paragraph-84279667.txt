A paired measurement of how a localized right-to-left interface changes a screenshot-driven computer-use agent's success, made inside one executable desktop benchmark and deliberately narrower than localizing a whole operating system. For one office suite whose tasks, documents, instructions, checkers and operating-system shell stay in English, one system-level configuration file sets two factors independently: the application's interface language (English or Arabic, through both of the application's language keys) and its layout direction (left-to-right or mirrored, through the application's own direction key). A fifth cell keeps English left-to-right and only puts each toolbar's buttons in a fixed random order, a relocation of the most-clicked controls with no change of direction. The measurement is a census of the benchmark's office-suite tasks that pass fixed rules blind to outcomes (106 candidates): four episodes per task and cell (two in the rearranged cell), split across two agent scaffolds, in one session. The layout and text main effects sum to the total change. The layout effect is reported as a net change on these tasks, decided with a dual equivalence margin (5 points absolute and a 15% ratio of solve rates, which never-solved tasks cannot dilute); it may be called direction-specific only if the mirrored cell does worse than the rearranged cell across tasks. Before any model runs, every cell is compared with English left-to-right at each task's starting screen by a render oracle (element positions located from pixels rather than accessibility extents, text-run identity, document identity, window titles, the English configuration against the unmodified application, planted positive controls), and each task's reference answer and empty starting state are saved in every cell and re-scored by the benchmark's own checker, so a task is excluded only where a cell would change a verdict without any agent. A CPU-only pilot has run this check with a generated Arabic-script stand-in for the application's shipped translations; the shipped translations, the virtual-machine image that carries them and the input-path re-certification on that image have not run.
