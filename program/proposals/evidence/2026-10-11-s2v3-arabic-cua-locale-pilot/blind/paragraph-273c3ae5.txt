A multilingual interactive benchmark for computer-use agents on a commercial desktop operating system: about 200 tasks across roughly 30 applications, run in virtual machines, each available in five system languages including one right-to-left language, with machine-translated task instructions. Six agents (proprietary and open) are run once per task and language, and success is checked by scripts. The paper compares success across languages and reports that the right-to-left language has the lowest success (about 13.7% against 19.3% for English, averaged over agents); a further analysis gives one agent English instructions inside localized interfaces. In the right-to-left condition the whole operating system is localized at once: the system shell and every application change script, translated strings and layout direction together, and in the matched condition the instruction language changes too. The authors attribute the right-to-left drop to the visual complexity of the script, the mirrored layout, or both, with no condition that separates them, and report no significance tests or intervals; an appendix anecdote shows an agent clicking where an icon would sit without mirroring. The benchmark also includes a pop-up deception safety subset.
