A multilingual interactive benchmark for computer-use agents on a commercial desktop operating system: about two hundred tasks over roughly thirty applications in virtual machines, each offered in five system languages, one of them right-to-left, with machine-translated instructions and script-based success checks. Six agents are each run once per task and language. Success is lowest in the right-to-left language (about 14% against 19% in English, averaged over agents), and a cross-lingual analysis gives one agent English instructions inside localized interfaces. Localizing the system language changes the shell and every application at once, so script, translated strings and layout direction vary together, and in the matched condition the instruction language changes as well. The drop is attributed to the script, the mirrored layout or both; no condition separates them, no intervals or tests are reported, and an appendix example shows an agent clicking where a control would sit without mirroring.
