Under a fixed resident-memory ceiling on one consumer machine, compare deployable configurations of large language models on short-answer factual recall. One configuration is a very large sparse mixture-of-experts model (about a trillion parameters) post-training quantized to under 2 bits per weight; its file is about twice the memory ceiling, so on the target machine it can only run by streaming expert weights from local storage, at roughly a twentieth of the resident models' decode speed. The others are smaller models from three different families that stay resident at 2 to 4.5 bits per weight. Matching is by eligibility, not by file size: every configuration must run on the same machine within the same resident ceiling, and each is labelled by tier (fits, tight, streamed). All configurations are run on server GPUs in one fixed non-reasoning mode with each vendor's recommended sampling, on the same frozen items with three seeded samples per item, and graded by a fixed judge model that is not a contestant, audited against blind hand labels. The decision rule is asymmetric. The giant is declared not worth its speed cost if, for any resident model, the multiplicity-adjusted upper confidence bound of its accuracy advantage is below a 5-point practical margin. It is declared better only if it beats every resident model (an intersection-union test) by at least that margin, on two benchmarks whose contamination exposure runs in opposite directions. A conditional check gives the best resident model a reasoning budget equal to the tokens it can decode in the wall-clock time the streamed giant needs per item. The study tests whether the giant's parameter surplus, which should favour factual recall, survives sub-2-bit quantization, and it maps each reading to which model to run locally.
