A screenshot-reading desktop agent, decoded greedily, disagrees with itself when the same task is rerun. Each step's request to the model contains every earlier reply and screenshot, so the first difference anywhere, one decoded token or a few pixels, makes all later requests differ, and several sources may each be enough to start that divergence. The method measures, on fixed requests, how often each source alone changes a step's reply. Requests from the agent's own episodes are replayed byte for byte through the inference server under a reference configuration (one request at a time, prefix cache off) and under the production configuration (batched, prefix cache on, with concurrent load like the original runs), and batching and caching are also varied separately. Copies of the same requests that differ only in the pixels of the on-screen clock, or only in other time-varying screen regions, are replayed under both configurations. This gives a factorial of observation perturbation by serving configuration whose cells estimate each source's per-step chance of changing the reply text and the parsed action, and their interaction. Separately, the recorded action sequences of earlier episodes are replayed open-loop, twice, in freshly reset virtual machines, capturing every intermediate screen, to measure how often the environment alone changes a screen or the final pass/fail verdict. Because the sources may be jointly redundant, the method reports per-source sufficiency rates rather than additive shares of disagreement, and combines them with the environment's verdict noise to predict rerun disagreement when each source is removed.
