A screenshot-driven desktop agent decoded greedily often reaches a different verdict when the same task is rerun. Every model request carries all earlier replies, reasoning included, and all earlier screenshots, so the first step at which two runs' reply text differs makes every later request differ: divergence is absorbing, and in the original runs it starts at the very first step in about nine pairs of ten. The method measures, at that onset step, how often each candidate source alone is enough to change the reply and the chosen action. It builds a fully crossed factorial on fixed first-step requests: the request itself, or a copy whose clock region alone, or whose other screen regions alone, or both, are taken from a second boot's real screenshot of the same task, each answered by a serving configuration verified to be bitwise deterministic and by the production configuration under production-like concurrent load. The cell with every source active must reproduce the original closed-loop runs' own first-step divergence before any attribution is made, and the second step is measured the same way as a secondary. Separately, the recorded action sequences are replayed open loop, twice, in freshly reset machines, to measure how often the environment alone changes the screen or the pass or fail verdict. A two-stage model, an onset hazard followed by a post-onset action-divergence rate estimated on the original runs, turns the measured onset hazards into a predicted rerun disagreement for each source removed, registered in advance for a later closed-loop test.
