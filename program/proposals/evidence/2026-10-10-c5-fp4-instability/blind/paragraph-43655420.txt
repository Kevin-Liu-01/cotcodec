A small decoder-only language model is trained from scratch on a fixed educational web corpus with every linear layer, except those in the last block, the embeddings and the output head, computed in emulated 4-bit block-scaled arithmetic in all three matrix products of each step (forward, input gradient, weight gradient). Two 4-bit element grids with the same number of codes, a non-uniform floating-point grid with two exponent bits and a uniform symmetric integer grid, are crossed with four block-scale configurations chosen so that block size and scale encoding can be separated at equal storage: a power-of-two scale on blocks of 32 (4.25 bits per element), the same power-of-two scale on blocks of 16 (4.5 bits), an 8-bit floating-point scale with a per-tensor 32-bit scale on blocks of 16 (4.5 bits), and a 16-bit floating-point scale on blocks of 32 (4.5 bits); a full-precision model is the reference. Scales are chosen by one round-up absolute-maximum rule, forward operands use round-to-nearest and output gradients stochastic rounding, no rotation is applied, and every decoded operand is exactly representable in the matrix-multiply input format, so all cells share one exact emulation path. Each configuration gets its own learning-rate sweep, then three fresh seeds that share initialisation and data order across cells. A first stage runs only the configurations matching the two commercial formats plus the reference, and continues only if the documented gap between those two is resolved. The final validation-loss differences are decomposed into a grid effect, a block-size step, a scale-encoding step and an equal-storage trade, and their interactions with the grid, with 90% intervals and pre-registered three-way decisions. A tensor-level prediction, that power-of-two scales penalise the uniform grid while fine scales leave the two grids near parity, is computed from block signal-to-noise on tensors captured from the reference model and frozen before the factorial runs.
