A small decoder-only language model is trained from scratch on a fixed educational web corpus, with every linear layer except those of the last block, the embeddings and the output head computed in emulated 4-bit block-scaled arithmetic in all three matrix products of each step. The study measures in training loss a published signal-to-noise prediction: that restricting the shared block scale to powers of two penalises a uniform integer 4-bit grid more than a floating-point 4-bit grid with the same number of codes. The two grids are crossed with five block-scale configurations: power-of-two scales on blocks of 32 and of 16, 8-bit floating-point scales (four exponent and three mantissa bits, with a per-tensor 32-bit scale) on blocks of 32 and of 16, and a 16-bit floating-point scale on blocks of 32. Within each block size the power-of-two and 8-bit scales use the same storage, so the grid-by-scale crossing is measured at matched storage at two block sizes. The registered test compares the power-of-two and 16-bit scales on blocks of 32, which share block size and exponent range and differ only in the scale's mantissa, so neither a block-size (crest-factor) interaction nor the 8-bit scale's limited range can produce it; a tensor-level computation with the registered quantizer shows the contrast vanishing when scale rounding is removed and unchanged when the range limit is removed. Every decoded operand is exactly representable in the matrix-multiply input format, so all cells share one exact emulation path. Before the factorial, a probe on its own seeds measures seed-to-seed noise and the gap between the two commercial-format analogues at the full training budget; it stops the study if that gap is unresolved and otherwise sets the number of seeds, and no probe run enters the factorial. Each cell gets its own learning-rate sweep under one protocol for both grids, then fresh seeds. The test is decided on 95% intervals with an equivalence band set by the probe's gap, and a second evaluation of the same weights with a full-precision forward pass separates effects stored in the weights from forward-pass rounding.
