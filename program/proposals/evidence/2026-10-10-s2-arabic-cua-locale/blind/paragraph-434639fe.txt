A self-hosted team-chat web application with deterministic state graders is internationalized so that every interface string comes from a message catalog and the locale is a parameter of each task fixture, while workspace content, the strings the graders check, and the task instructions stay in English. Four locale cells cross interface-text language (English or Arabic) with layout direction (left-to-right, or mirrored right-to-left through the document direction attribute and logical style properties), so English text in a mirrored layout and Arabic text in an unmirrored layout are both rendered. Before any model runs, an oracle gate must pass in every cell on three fixture seeds: scripted reference solutions keyed to stable test identifiers, and their coordinate replays through the agent's own action executor, reach the graded goal on every task; the accessibility role and identifier tree is identical across cells; each mirrored cell's element boxes match the horizontal reflection of its unmirrored counterpart within a few pixels with no clipping or new overlap; the English build is pixel-identical to the build before extraction; English content keeps its character order inside right-to-left containers; and rendered Arabic interface strings survive an optical-character-recognition round trip against a control rendering. An English-only pilot of one open vision-language model acting on screenshots then measures per-task base rates, seed-and-rerun outcome variance and accelerator cost, and a fixed rule admits the main study only if a paired design on the informative tasks can detect a 5-point direction main effect with 80% power inside a compute cap. The main study runs all four cells on the same seeds within one serving session and estimates the direction and text main effects, which sum exactly to the total English-to-mirrored-Arabic drop, and their interaction, by paired t-tests on task means with tasks as the random factor and equivalence tests at plus or minus 5 points, with pre-registered moderators for target relocation across screen halves, direction-bearing steps, and lost word overlap between instructions and interface labels.
