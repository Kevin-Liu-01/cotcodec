A frozen language model's key-value cache for a long document is replaced, layer by layer and head by head, with a much smaller set of keys and values, so that the model answering questions without the document behaves as if the document were in context. The compact keys are restricted to a subset of the document's own cached keys, chosen either as the keys that receive the most attention from a set of reference queries generated about the document or by greedy orthogonal matching pursuit; given those keys, the compact values are fitted by least squares and a scalar bias per kept key by non-negative least squares, so that each head's attention output and total attention mass over the reference queries are reproduced. This closed-form method is compared, at matched cache size and across compaction ratios from 2x to 100x on long-document question-answering benchmarks, with an unconstrained alternative that trains a small free key-value prefix end to end by distillation: the prefix is initialised from the document's first tokens' cache and optimized to minimize the KL divergence to the model with the full document in context, on synthetic conversations about the document that the model generates itself. The confined method matches or beats the free one at moderate compaction and loses at extreme compaction, which the authors attribute to the free method not being restricted to selecting keys from the original cache. A later controlled study compares both representation-based methods with storage-matched low-rank and adapter fine-tuning for injecting a document's knowledge.
