A frozen pretrained decoder language model is shown eight input-output demonstrations of a task followed by a query, and its next-token distribution at the answer position is recorded. The same frozen model then reads the query without the demonstrations while a small per-episode state is applied at four residual-stream depths: at each depth the residual is projected onto a fixed 64-dimensional subspace estimated without any task text (the principal directions along which a longer context changes residuals on generic web text, after whitening), extended by a constant coordinate, multiplied by a rank-8 matrix and written back into the same subspace. For each demonstration set, states are fitted by gradient descent to minimize the KL divergence to the model's own eight-shot predictions on sixteen fitting queries and are scored on eight held-out queries. Four nested classes are compared: no state; one state shared by every demonstration set of a task family; that shared state plus a per-episode part whose row space is confined to the span of the eight demonstrations' own projected input representations after one linear map shared by all episodes; and the shared state plus an unconstrained rank-8 per-episode part. The confined class contains every update made of outer products between an error vector and a demonstration's input representation, including first-order steps with a fixed preconditioner and recursive least squares; the unconstrained class bounds what any write rule at this interface could reproduce. Synthetic task families are admitted only if the model's accuracy falls when the demonstrations' labels are deranged, and families whose correct mapping changes between episodes carry the decisions. The procedure stops if too few families are admitted, if the shared state already explains the behaviour, if the unconstrained state removes less than half of the per-episode divergence the shared state leaves, or if the confined class matches the unconstrained one within a fixed margin; planted states of known class, passed through the same read path, must be recovered and told apart before anything is read.
