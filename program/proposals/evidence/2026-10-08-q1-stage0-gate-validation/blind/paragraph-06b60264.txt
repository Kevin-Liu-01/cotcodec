Correctness checkers of a GPU-kernel benchmark are scored by how many injected faults they detect. For each benchmark problem a correct CUDA implementation, written by a language model and admitted only if it passes the benchmark's own check on every input suite, serves as the mutation target, while the benchmark's reference model remains the oracle. Deterministic rules in six fault families (arithmetic, indexing, semantic, boundary, synchronization, precision) inject single-site faults; mutants that do not compile, that compile to the same binary as the original, or that crash are filtered out. A mutant enters the denominator only if a kill witness exists: an input, admitted by a validity gate that discards inputs on which correct implementations already disagree with the reference, on which the mutant's output differs from the reference beyond tolerance. Each checking protocol (the benchmark's five random inputs at a tolerance of 1e-2, a variant with hidden input scalings and a tolerance of 1e-3, a fuzzing recipe, and small input suites chosen by set cover over the mutant-by-input kill matrix and checked on held-out mutants) is scored by the share of witnessed mutants it misses, per fault family, together with how often it rejects correct implementations.
